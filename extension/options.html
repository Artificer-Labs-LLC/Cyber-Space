✨ Cyberspace Resolver — Settings

The extension resolves .cyberspace names through this DNS-over-HTTPS bridge. Leave empty to use the genesis bridge (http://185.143.228.228/dns-query). Must be a full http(s) URL with a path. Save (button, blur, or Enter) commits the value — changing it drops the cached health check so the next popup open re-checks live. "Check bridge now" runs a live resolve of genesis.cyberspace against the endpoint currently in the box (unsaved edits included), with no health-cache lookup.
